# 当前状态与接手事项

核对日期：2026-11-26。本仓库从 AI 连接知识库的采集器开发代码独立整理，包含同页多控件汇总和审计后的脱敏修复。原知识库和旧版稳定发布保留；本仓库尚未发布独立稳定 EXE。

## 已有源码

- 固定专用 Chrome 的启动、复用与 CDP 连接。
- 普通主页面控件的右键标注、定位资料和用途说明保存。
- 同页已标注控件汇总为页面任务包，保留来源与草稿状态。
- 小悬浮窗、独立设置、文件日志、应用图标和两份配套技能。

独立整理后，45 项纯单元测试通过，Python 语法与本地引用检查通过。未将这些结果视为 GUI、冻结 EXE 或模型任务验收。

## ZCode 可见对话接入待完成

用户要求：发送本页控件后，ZCode 对话栏目出现对应任务，可以打开同一对话继续提问和整理经验。

目前主程序只导出并复制页面任务，尚未实现上述自动投递。可选的旧 `zcode_runner.py` 是独立 CLI 适配，不能保证界面可见。

本机实际检查发现两套不同入口：

- 已安装桌面版为 3.16.3，内置 CLI 为 0.17.0，入口位于 `%LOCALAPPDATA%/Programs/ZCode/resources/glm/zcode.cjs`。
- 旧适配默认候选仍含 `D:/ZCode/Bin/zcode.cmd`，此前对应开发 CLI 0.16.9。接入时应识别用户实际安装，不能把这两套运行环境混用。

安装版 `--surface desktop` 只影响呈现上下文，不会把 CLI 任务自动登记到桌面对话栏。内部任务创建服务会更新索引并广播事件，但本轮只确认其通过 Electron 内部 MessagePort 使用，尚未核实可供外部采集器调用的公开入口。工作区深链只打开目录，也不等于创建或打开指定对话。UI 插件的消息能力需要绑定已有会话。

后续验收应覆盖：发送后取得可核对的会话标识 → 对话栏目出现 → 打开同一会话看到页面任务 → 在其中发送第二轮并继续整理。不要通过直接写用户会话数据库伪造接入，也不要用 CLI 退出成功代替该闭环。

## 界面与支持范围

小悬浮窗在高 DPI 下曾发现内容裁切，布局已继续调整，当前版本仍需实际窗口复验。普通主页面 DOM 为当前范围；iframe、Shadow DOM、Canvas 内部对象暂不支持。

页面合集不是全页面事件录像，保存顺序不是操作顺序。生成的能力保持 draft，业务验证需要明确任务与实际结果证据。
