广场中的公开对话由 `plaza/worker.py:401` 读取原生会话快照，经过公开文本过滤后交给自己的网页显示。这与“ZCode 桌面侧栏已显示该会话”是两项结果。其 README 也没有承诺向当前桌面窗口热刷新外部索引。

广场默认角色模式是 `yolo`（`plaza/store.py:468`）。它没有自动批准全部权限的处理器：未专门支持的反向请求会明确阻塞。因此，后台通信方式与权限模式必须分别设置、分别验证。

不直接复制旧桌面同步 SQL：当前安装版包含新版 host、project、root 与 CLI 状态字段，采集器保留自己的四表结构和版本核对。当前任务已有真实模型会话，也不需要移植广场用于持久化空会话的 SDK helper。
