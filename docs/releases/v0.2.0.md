**尚未发布。后台原 SID 续聊、Bash 语法检查与 owned 索引 mode 更新已实测；GUI 已显示并打开原会话；桌面同会话续聊已收到可见回复；最新候选重新启动/最终包仍待验收。**

## 本版行为

- 小置顶窗口连接固定专用 Chrome，普通主页面右键标注并保存。
- “整理本页标注（ZCode）”把已保存同页卡片合为完整脱敏包，生成统一技能说明、页面约定和候选 runner 草稿。
- 主路径为安装版 Electron Node 的 app-server stdio，参考 Plaza runtime、持久 SID 与事件订阅；session/send ACK 是受理，等待真实终态和最终快照后才登记。
- 用户明确授权采集器任务 mode=yolo 完全访问，可做格式/引用/语法检查；scope 仍为 draft，不连接网站、不执行业务、不运行候选 runner。
- 用户选择的私有索引适配核对真实会话、版本/schema，备份后窄范围登记。只有本工具 owned-marker 与同 SID/taskPath 匹配旧行可只改 mode，外来任务与其他列不动。
- 保存真实 SID，用户在 ZCode 同项目打开原会话继续；悬浮窗没有续聊输入框。

沿用已有认证与模型，不改全局默认或其他 Plaza 角色。启动、刷新、采集不调用模型；点击整理才提交任务，后台不依赖桌面焦点。CLI -p runner 保留作可选 mode 的源码 fallback，主路径使用 app-server。
