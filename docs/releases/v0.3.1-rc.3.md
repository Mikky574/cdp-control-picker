# CDP 控件采集器 v0.3.1-rc.3

- Windows x64 便携包新增 Prepare-Chrome.cmd。显式运行后从 Google 的 Stable 目录下载和校验完整桌面 Chrome for Testing。部署时先解压便携包，再运行准备入口。
- 「启动 Chrome」先复用可达的 Chrome CDP，否则启动专用窗口。浏览器查找优先使用明确指定的路径，然后查找已安装的 Chrome，最后自动识别便携包旁的可选浏览器。
- 9222 被其他服务占用时，可在设置选择并保存其他空闲回环地址。浏览器资料独立，首次在专用窗口手动登录。
- 部署技能和人用 HTML 补齐已有端点、缺 Chrome、离线迁移、端口冲突与检查方法。

本机实测冻结 EXE 的 Google 下载和完整性校验，并在模拟无系统 Chrome 查找结果时自动发现官方便携浏览器，打开真实窗口，建立回环 CDP，第二次启动复用原实例。Windows x64 的此次验收使用 Chrome for Testing 158.0.8127.88。App 内版本为 0.3.1。
