# CDP 控件采集器 v0.3.1-rc.2

右键采集表单删除原来隐藏的「允许的动作」。新控件卡和由它们组成的页面包只记录网页位置、定位候选、名称、用途及可选的预期结果与条件。ZCode 根据实际页面和当前任务判断怎样操作。原有录入及归档的旧包保留原数据，新学习任务不会把旧动作字段当作门槛。

冻结 Windows EXE 用虚构订单页实际右键采集并保存了输入框和一个详情按钮。输入框的 CSS ID 命中 1 个控件。页面上两个详情按钮共用测试属性，采集器用订单行限定范围，唯一命中选中的按钮。用采集器的「复制交接说明」导出页面包，再用同一个 EXE 的只读检查重新定位，2 个控件均成功。

原生 ZCode 发送路径沿用 rc.1。本机 ZCode 4.0.0 实测中，点击发送约 10 秒后已显示首条控件说明和「停止生成」。约 85 秒后本轮结束，「在 ZCode 查看」打开原会话。该机侧栏的专属项目显示为 `cdp-picker-bridge`。3.18.2 的目标机仍待验收。

源码回归 331 项运行，330 通过，1 项因 Windows symlink 权限跳过。Node 连接桥综合测试通过。App 版本仍为 0.3.1，稳定版 Latest 为 0.3.0。
