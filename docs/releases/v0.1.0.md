# CDP 控件采集器 v0.1.0 · 可用采集版

这是此前用户已确认可以操作的 Windows 面板版，迁移到独立仓库发布。EXE 与原稳定发布逐字节一致，SHA-256 为 `3a048839002bec2ff311a517d538d5defc7120fc3e7dc65fe92a566c8d08042b`。

推荐下载 **CDP-Control-Picker-v0.1.0.zip**，解压到可写目录后双击 EXE。采集部分不需要安装 Python、Node 或 ZCode。

## 操作顺序

启动专用 Chrome 并由人登录 → 刷新页面列表 → 展开下拉框选页 → 连接所选页 → 开启右键采集 → 回到同一网页右键控件、填写用途并保存。

程序继续使用 EXE 同目录的 `CDP-Chrome-Profile` 和 `CDP-Picker-Workspace`。升级或换目录时保留原资料，也可在面板选择原工作区。发布包不包含个人浏览器资料或采集记录。

## 版本对应

本发布对应本仓库 `v0.1.0` 标签及 `release/0.1.x` 分支。源码来自原知识库提交 `307baaed7ace7fdb2cc1b6d86e3173904187c00e` 中的采集器与所需文件；具体来源和每个文件的校验记录在 `SOURCE_ORIGIN.json`。

`main` 保留独立整理后的开发源码，包括悬浮窗和同页控件合并。这些开发改动未包含在本 EXE 中。

v0.1.0 按选中的单张控件卡交接。自动投递到 ZCode 可见对话尚未接入，CLI 的完整权限链路也尚未完成实际任务验证。支持普通主页面 DOM 控件；iframe、Shadow DOM、Canvas 内部对象暂不支持。能力生成结果属于待验证草稿。
