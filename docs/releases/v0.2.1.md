# v0.2.1：在小悬浮窗管理本页控件

新增本页列表与标注管理，保留小悬浮窗和仅交接上下文的范围。0.2.0说明继续作为对应版本历史保留。

- “本页控件”可展开/收起，列表显示序号、名称、用途。
- “编辑”可改名称、功能说明、允许动作、前置条件、预期结果；页面地址与定位证据只读。
- “删除”确认后只移入本地回收区；旧交接包与已发ZCode会话保留快照。
- “上移 / 下移”调整前后并自动勾选“按此顺序操作”；取消勾选时只是排列。
- 发送携带最新标注与sequence。勾选顺序是用户声明、未执行验证，不会触发网页动作。

首轮范围保持：ZCode读完整控件上下文，简短确认后等待用户；不自动生成技能、脚本、计划或执行步骤。用户后续在ZCode自行继续。

app-server stdio、选定工作区/会话yolo完全访问、真实SID和私有索引兼容登记继续沿用，不改其他项目或全局模型设置。适配目标仍为ZCode3.16.3.8992 / CLI0.17.0。
