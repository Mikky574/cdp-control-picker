CDP 控件采集器 v0.2.0 · Windows 便携版

用途：把网页中已标注控件的位置与用途交给ZCode，收到简短确认后，你在ZCode继续自己的工作。

使用前：电脑已有Google Chrome与ZCode。当前适配ZCode 3.16.3.8992（内置CLI 0.17.0），无需另装Python或Node。

1. 解压到可写目录，启动CDP-Control-Picker-v0.2.0.exe。
2. 点击启动Chrome，在这个专用浏览器里登录网站。
3. 刷新并选择目标页，连接后开启采集。
4. 右键需要的控件，填写名称和用途后保存；同一页可保存多个。
5. 点击“发给 ZCode”。ZCode读取完整资料并简短确认；到对应项目打开对话，自己补充信息和后续任务。

“复制交接说明”只复制一句供你粘贴到已有对话的任务，不自动发送。相同标注已有对话时复用原对话。
首轮只交接上下文，不自动生成技能、脚本或后续计划，也不操作业务网站。

本工具为你选定的记录工作区/会话采用“完全访问”（yolo），不改其他项目或全局模型设置。
设置仅本次运行生效。关闭软件会保留本地资料。

默认资料在EXE旁：CDP-Picker-Workspace保存标注与交接记录，CDP-Chrome-Profile保存专用浏览器登录资料。
以后继续从同一目录启动并保留这两个目录，可沿用仍有效的登录；过期时回专用Chrome重新登录。
仅支持普通主页面控件；iframe、Shadow DOM和Canvas内部对象暂不支持。
