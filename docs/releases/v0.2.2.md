# v0.2.2：更紧凑的卡片界面

本版将控件管理改为卡片与紧凑连接区，按实际字体尺寸安排布局。0.2.1发布说明保留为对应版本历史。

- 顶部保留品牌与设置，页签只显示标题和域名；连接工具收为“Chrome / 刷新 / 开启采集 / 断开”一行。
- “本页控件 · N”可收起，固定视口内滚动；每卡序号、完整换行名称、动作tag、两行用途摘要和编辑/删除/上移/下移。
- 移除选中后的重复大详情和全局四按钮排，详细内容在编辑弹窗，记录目录与日志入口放设置。
- 目标约360dip宽，按实际字体metrics布局；可用空间不足时收缩卡片视口，保留主要操作。
- 顺序checkbox仍为“按此顺序操作”，主按钮“发给 ZCode”，次按钮简写“复制说明”。

数据层、软删除快照、声明顺序与ZCode app-server机制不变；首轮只读完整上下文、简短确认后等待用户，不生成能力文件或执行步骤。

全suite152项，151通过、1项原Windows真实symlink权限跳过，替代门禁通过。卡片组件6项及应用相关24项通过，覆盖五档100%–200%缩放、175%/14pt、窄宽、多卡、空态与busy；完整主窗五档工具栏无重叠/越界，展开不超可用屏幕边界，收起尺寸减小。

构建输入hash前后一致，EXE --package-check退出0，cards/fontAware=true、5项管理入口及资源齐备；实际归档8模块含capture_list，无DesktopBridge，字节码确认CaptureList和4个新适配方法。成品检查不打开窗口、浏览器或模型；真实widget始终withdrawn，本版无最终可见GUI或浏览器/CLI/模型新端到端测试。详见[验证记录](../cdp-picker-validation.md)。
