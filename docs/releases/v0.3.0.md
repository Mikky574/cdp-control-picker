# v0.3.0：让ZCode实际学习和验证CDP能力

本版在现有窄窗、控件管理及持久发送回执之上，补齐采集后的实际使用链路。

- 任务正文不再显示内部handoff号；工作区内的context.md明确指向本次技能和页面包。
- 发送实际CDP端点、当前选中页签、页面和路由摘要；不猜同址页、不另开匿名浏览器。
- EXE提供无窗口的JSON任务入口，ZCode无需安装Python/Node/Playwright就能检查控件和逐步尝试获准动作。
- 每一步act有本地执行记录；未知不自动重发，不把点击派发当成业务成功。
- 产出独立学习报告、技能、页面约定及带参数的调用步骤，分别记录连接、定位和流程的真实验证范围。

涉及生产提交、删除、付款或缺少参数时，先明确具体任务与缺项。旧context-only资料包保留原语义。源代码使用独立学习分支，既有界面改动保留。

测试与冻结EXE检查以[验证记录](../cdp-picker-validation.md)的本版段落为准。

实测：234项自动测试中233通过、1项环境权限跳过。后台ZCode已经在现有Chrome的虚构本地查询页自行调用运行器完成检查、填写、查询和回读，独立服务确认查询1次、业务写入0；同job重执行没有再次查询。学习报告、页面约定和步骤JSON有效，生成技能通过校验。真实网站仍需按各自参数与授权验证。
