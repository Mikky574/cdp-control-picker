# CDP 控件采集器 v0.3.1-rc.7

下载 CDP-Control-Picker-v0.3.1-rc.7-windows-x64.zip，完整解压后打开 Deployment-Guide.html。整包包含 EXE、Chromium、ZCode 连接桥、HTML 指南和四份技能。

- 网页的「控件采集模式」提示可拖动和隐藏。隐藏后仍可右键采集，点「停止」才结束采集。
- 学习技能可延续同一个业务问题，按各自的目标和回执交错处理独立任务。
- CDP 支持在同一已登录浏览器另开同源研究页签，查找可见控件候选。不同研究页签分别核对路由与结果。已标注页面仍可按原方式恢复和查询。

使用冻结 EXE 和 Chromium 在虚构页面验证了两条查询交错返回、研究页签定位、关页恢复，以及提示拖动、隐藏后右键和停止。Python 测试 339 项，338 项通过，1 项按 Windows symlink 条件跳过，ZCode 连接桥协议测试通过。

本版为 Windows x64 候选版。随包的 Chromium 用于无 Chrome 环境下的离线部署和 CDP 试用，无自动更新。目标机上的 ZCode 客户端及其账号需单独准备。
