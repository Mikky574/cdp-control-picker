# CDP 控件采集器 v0.3.1-rc.6

下载 CDP-Control-Picker-v0.3.1-rc.6-windows-x64.zip，完整解压后阅读 Deployment-Guide.html。整包包括采集器 EXE、开源 Chromium、ZCode 连接桥、使用指南及四份技能。采集器无需目标机安装 Python。系统没装 Chrome 时，点「启动 Chrome」可直接用随包 Chromium。ZCode 客户端及其账号仍需要在目标机配置。

旧页签关闭后，学习能力可以通过本机 CDP 在原浏览器重新打开已知业务网址并核对页面。已验证的只读接口继续沿用浏览器登录状态，可直接执行一次查询。重复调用优先使用已恢复的页签。旧学习资料可以继续使用，迁移时将其运行入口指向新版 EXE。

冻结 EXE 在隔离的订单查询网页上通过了关页、恢复、复用原 HttpOnly 登录会话和单次接口回读。重复准备不会多开页签。Python 测试 337 项，336 项通过，1 项因 Windows symlink 权限跳过。ZCode 连接桥需按目标机的部署指南进行首次授权。

本版是 Windows x64 候选版。附带的 Chromium 快照用于无 Chrome 环境的 CDP 试用，无自动更新机制。
