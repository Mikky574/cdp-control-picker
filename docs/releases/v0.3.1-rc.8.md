# CDP 控件采集器 v0.3.1-rc.8

修复 GitHub 搜索等网页弹窗抢走标注框键盘焦点的问题。右键输入框后自动聚焦用途字段，保存或取消后把焦点交回原控件。

在未登录的 GitHub 官网搜索输入框实测。旧版无法把焦点移入用途字段。新版可输入并保存中文标注，原搜索词保持不变，保存后焦点恢复。独立回归覆盖网页脚本焦点限制、原生网页弹窗、Tab、取消和保存。

下载 CDP-Control-Picker-v0.3.1-rc.8-windows-x64.zip，完整解压后查看 Deployment-Guide.html。整包含采集器 EXE、Chromium、ZCode 连接桥、HTML 指南和四份技能。系统没装 Chrome 时可直接使用随包 Chromium。ZCode 客户端和账号需在目标机准备。
