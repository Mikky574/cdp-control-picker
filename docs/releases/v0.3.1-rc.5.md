# CDP 控件采集器 v0.3.1-rc.5

- 学习任务以业务输入、对象、实际请求和完成信号为主。控件顺序帮助初次理解，后续按经过验证的最短路径完成任务。
- CDP 运行器新增限时被动网络观察和单次同源 JSON 查询。只读查询沿用原浏览器当前会话，返回明确选择的字段。接口契约需用正常页面路径或项目证据验证。
- Windows x64 可选依赖配套步骤增加 Google 官方离线 MSI 安装指引。遇到缺 Chrome 且包里有安装器时，采集器提示安装入口。GitHub 便携包另保留从 Google 下载桌面 Chrome 的准备脚本。

在真实 Chrome 的虚构订单页用冻结 EXE 验证了网页操作与单次 GET 的结果一致。两条不同编号各一次查询均通过，复用 HttpOnly 登录会话，输出无 Cookie 或未选择字段。Python 回归 335 项，334 通过，1 项因 Windows symlink 权限跳过。
