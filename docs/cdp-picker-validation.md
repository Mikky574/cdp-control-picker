# CDP 控件采集器首版验证

日期：2026-11-26。版本：0.1.0，Windows 独立 EXE，采集层使用直接 CDP，不依赖目标机安装 Python 或 Node。

## 已完成的验证

- Python 离线测试 36 项：CDP 协议响应与并发、断线与超时、工作区保存、凭据字段排除、CLI 参数传递和任务状态，以及浏览器启动和端口复用。
- 页面采集层的隔离 Playwright 检查：右键浮层、描述必填、保存 binding、业务行限定、关闭恢复普通右键、敏感输入排除、刷新、窄屏与不支持的页面结构。
- 真实隔离 CDP 集成 14 项：独立 Chromium 和随机端口，右键采集回传 Python，读取可访问性 role/name，保存工作区；刷新后原定位仍可重新查找；断开采集客户端后浏览器和页签保留。
- 真实隔离浏览器启动 8 项：启动可见 Chromium、再次调用复用同一实例、独立资料目录、关闭测试浏览器后沿用同一资料重启，假站的持久 Cookie 和 localStorage 保留。
- 桌面界面启动、采集卡显示、可访问性字段保存、定位验证记录和打包资源检查。
- 独立 EXE 已启动验证；GUI 预览中发现的窄窗口入口遮挡已通过“控件记录 / ZCode 任务与日志”选项卡调整。用户按 Esc 停止桌面检查后，没有继续操作窗口。

所有浏览器测试使用自建的测试浏览器和本地演示站，没有使用用户的 9222 浏览器、真实登录凭据或业务对象。测试结束后关闭了测试浏览器与服务。

## 首版范围

支持普通网页主 frame 的常见 DOM 控件。iframe、Shadow DOM、Canvas 内部对象和浏览器内部页面不应被当作已支持。网站更早注册的右键处理器仍可能有行为，单独拦截后续 contextmenu 不能撤销已经发生的动作。

默认使用固定的专用 Chrome 资料目录；复用现有 CDP 端点时仅确认了调试端点可用，不假称已核对其实际 profile 或网站账号。持久资料帮助复用仍有效的会话，不保证永久登录。

ZCode 任务适配使用真实本机 CLI 的已核对入口，参数传递和终态处理通过 fake CLI 测试。首版集成没有代用户向模型提交真实业务采集任务，也没有验证自动生成的 runner 已能执行完整业务。

“定位唯一并高亮”属于定位验证。“生成了 skill、契约和脚本”属于能力草稿。业务执行成功需要后续按明确任务与授权单独验证。
